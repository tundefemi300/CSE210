# Mindfulness Program

## Overview

The Mindfulness Program is a console application written in C#. It helps users practice mindfulness through three guided activities.

The project demonstrates the object-oriented programming principles of:

- Abstraction
- Encapsulation
- Inheritance

## Activities

### Breathing Activity

Guides the user through slow breathing exercises to help them relax and reduce stress.

### Reflecting Activity

Encourages the user to reflect on meaningful experiences by displaying prompts and reflection questions.

### Listing Activity

Prompts the user to list as many positive responses as possible within a specified amount of time.

## Features

- Menu-driven interface
- Spinner animation
- Countdown animation
- Random prompts
- Random reflection questions
- Inheritance using a base Activity class
- Proper encapsulation with private fields
- Clean object-oriented design

## Technologies

- C#
- .NET 10
- Console Application

## How to Run

Open the project folder and execute:

```bash
dotnet run
```

Or build first:

```bash
dotnet build
```
